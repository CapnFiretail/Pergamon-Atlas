Atlas Navigation

Every game, tool, and artifact in Pergamon Atlas exists at a unique coordinate in the Atlas space and carries a permanent address code. Use this page to navigate by code, decode coordinates, or explore the system.

Navigate by Code

Enter an artifact code (found on any game or tool page) to go directly to that location in the Atlas.
