Help & FAQ

Everything you need to know about using the Pergamon Atlas — tools, games, navigation, and the Atlas itself.

Getting Started

What is the Pergamon Atlas?

The Pergamon Atlas is a collection of tools, games, and a coordinate-based navigation system called the Atlas. Visit the Atlas Explorer to learn more.

How do I find tools and games?

Browse the Tools and Games catalogs from the sidebar. You can also use the search bar in the header to find something specific.

Do I need an account?

No. All tools and games are free to use without an account. Accounts are coming soon and will unlock bookmarking and history features.

The Atlas System

What is an Atlas Address?

Every artifact (tool or game) has a unique address in the Atlas — a three-segment code like ATLAS-XXXXX-YYYYY-ZZZZZ. It represents the artifact's fixed location in Atlas coordinate space.

What is an Artifact Code?

The Artifact Code is a short identifier unique to each artifact, derived from when it was registered and its position. It appears in the Atlas Reference panel on every artifact page.

How do I jump to an address?

Open the Atlas Reference panel on any artifact page and use the Jump to Address field. Enter a full Atlas Address to navigate directly to that artifact.

Tools & Games

Are the tools free to use?

Yes — all tools run entirely in your browser and are free with no sign-in required.

Do the tools store my data?

No data is sent to any server when you use a tool. Everything runs locally in your browser session.

A tool isn't working — what should I do?

Try refreshing the page. If the problem continues, submit a bug report and describe what happened.

Feedback & Support

How do I suggest a new tool or game?

Use the Suggestions page. Select "Tool Idea" or "Game Idea" as the category and describe what you have in mind.

How do I report a bug?

Go to the Suggestions page and select "Bug Report." Describe the problem and which page it occurred on.

Will you reply to my suggestion?

If you include your email, we'll do our best to follow up. All suggestions are read regardless.
